# Christmas Memories · 圣诞回忆

单文件 Three.js 圣诞树，支持本地照片和可选的摄像头手势控制。没有后端；照片不会由本项目代码上传，刷新页面后清空。

## 运行

在项目目录打开终端：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8765/Christmas.html>。按 `Ctrl+C` 停止服务器。首次加载需要联网获取 Three.js、字体，以及启用手势时的 MediaPipe 运行库和模型。分享部署时使用 HTTPS；摄像头需要浏览器支持并由用户授权。

## 操作

- 点击“添加照片”，或把图片拖进窗口，或用 `Ctrl+V` 粘贴。最多保留 30 张，每张不超过 20 MB。顺序解码后将最长边缩小至最多 3072 像素，不修改原文件。解码失败或超限会提示并跳过。
- 自带的 “I Love You” 牌子固定排在第一张，导入照片后依然留在树上，用上一张、下一张循环浏览时可以翻到。它不计入 30 张上限，聚焦到它时可以手动删除。牌子的文字在 `createDefaultPhotos()` 里用 canvas 绘制，可直接改成自己的落款。
- “圣诞树”“散开”“查看照片”切换模式；上一张、下一张循环浏览；聚焦时可以删除当前照片。
- 在画面上按住拖拽可自由旋转，松手后恢复自动旋转；滚轮缩放，范围限制在 40 到 90 之间。
- 背景有飘雪、远景星空和偶尔划过的流星；圣诞树模式下树上缠着一圈闪烁彩灯，散开或查看照片时彩灯淡出。切换模式时中心会迸发一圈光点。
- 直接点击任意一张照片即可聚焦查看；鼠标悬停到照片上时光标会变成手形。
- `←` / `→` 切换照片，`Esc` 返回树形，`H` 隐藏或显示控制区。右上角按钮也可恢复控制区。
- 照片按原图比例适配标题与控制区之间的空间；隐藏控制区可获得更大的展示面积。
- 点击“启用手势”后再申请摄像头。允许后加载识别模型；启用期间可取消。关闭手势或离开页面时停止摄像头并释放模型。
- 握拳聚合，张手散开，捏合进入照片模式。在照片模式中把手移到右侧切换下一张，移到左侧切换上一张；连续切换间隔为 450 毫秒。方向与镜像预览一致。
- 手离开画面会清理识别锁定状态，并保留当前展示。真实识别效果取决于光线、手与镜头距离及设备性能。

## 检查

```powershell
node check.cjs
```

检查脚本直接提取页面中的生产逻辑，验证语法、手势翻页、照片索引及删除资源释放、适配计算、动画平滑、文件限制、指针缩放与拖拽换算、聚焦索引越界守卫、权限拒绝、取消启用与异步超时资源清理。它使用模拟关键点、DOM 和摄像头，不替代真实硬件测试。

浏览器检查时还应确认：不启用摄像头即可看到动画；横图和竖图不变形；失败图片不影响其他图片；关闭手势后摄像头指示灯熄灭；手机窗口和隐藏控制区后照片重新适配；拖拽旋转后松手能恢复自动旋转；点击照片与拖拽旋转不会互相误触发。

## 粒子特效

四种特效各自是一个 `THREE.Points`，每种只占一次 draw call，总共增加约 2600 个点、5 次 draw call：

- **飘雪**：加在 `scene` 上而不是 `mainGroup`，所以不跟随圣诞树旋转。落到底部后由 `wrapRange()` 环绕回顶部，并按各自的频率和相位做横向摆动。
- **彩灯**：加在 `mainGroup` 上，沿用装饰物同一条螺旋线公式，因此读起来像缠在树上的灯串。逐点颜色由 `twinkle()` 乘以存好的基准色，基准色单独保存，避免反复相乘衰减。只在圣诞树模式亮起。
- **星空**：半径 300 到 500 的球壳，`sizeAttenuation: false` 让星点保持固定像素大小。必须设 `fog: false`，否则指数雾会在这个距离把它们完全抹掉。
- **流星**：每颗流星是一个头部加一条 14 个点的拖尾，尾部亮度递减。熄灭后随机延迟几秒再从左上方重新发射。
- **爆发**：一个固定大小的点池，`setMode()` 改变模式和首次进入照片模式时调用 `fireBurst()` 复用，生命周期结束后自动隐藏。

数量都在 `CONFIG.effects` 里，任意一项设为 0 即可关闭该特效。

## 当前范围

保留原有粒子视觉和单 HTML 实现；没有引入框架、后端、持久化或大型渲染重构。

已做的桌面端优化：球体分段从 32×32 降到 16×12（场景三角形数约减少四分之三，肉眼无差别）；圣诞树模式下隐藏缩放为零的浮尘，省去每帧 2500 次 draw call；泛光按半分辨率渲染，窗口缩放后会重新按半分辨率应用。照片纹理启用各向异性过滤。渲染上下文丢失时会显示提示浮层而不是黑屏。

仍未做：粒子依然是独立 Mesh，约 4000 次 draw call，低性能设备上仍可能较慢，后续可考虑 Points 或 InstancedMesh。照片不持久化，刷新后清空。手势推理最多约 20 次/秒且在主线程，启用后会占用渲染帧，后续可考虑 Worker。移动端未做专项适配，30 张 3072 像素纹理在手机上很可能超出显存。

手势接口参考：[MediaPipe 官方 Web 指南](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js)。
